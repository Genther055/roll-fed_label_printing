# ROLL-PRINT CAD — Розкладка рулонної етикетки на погонний метр

Програмний комплекс для автоматизованого розрахунку та спуску смуг (imposition) самоклейних рулонних етикеток на погонний метр друку для цифрових та флексографічних машин.

---

## Основні можливості

1. **Імпорт та аналіз PDF**:
   - Автоматичне розпізнавання чистового розміру висічки (контур штанц-форми `CutContour`).
   - Автоматичне виявлення вильотів під обріз (Bleed, наприклад 2 мм).
   - Генерація векторного та растрового попереднього перегляду етикетки.

2. **Оптимізація розкладки на полотно 330 мм**:
   - Ширина матеріалу: **330 мм**.
   - Максимальна корисна ширина друку: **до 305 мм**.
   - Базова одиниця розрахунку: **1 погонний метр (1000 мм)**.
   - Точний розрахунок міжструмкових зазорів та кроку (рапорту).

3. **Підтримка двох типів нанесення**:
   - **Ручне нанесення (Manual)**:
     - Алгоритм **авто-максимізації**: порівнює книжкову (0°) та альбомну (90°) орієнтації.
     - Наочно демонструє, яка орієнтація дає більше етикеток на 1 погонний метр (наприклад, 266 шт/м проти 253 шт/м, заощаджуючи понад 5% матеріалу).
   - **Автоматичне нанесення (Аплікатор)**:
     - Повна підтримка міжнародних стандартів намотки **FINAT (Схеми 1–8)**:
       - Схема 1: Головою вперед (намотка назовні)
       - Схема 2: Ногами вперед (намотка назовні)
       - Схема 3: Правим боком вперед (намотка назовні)
       - Схема 4: Лівим боком вперед (намотка назовні)
       - Схеми 5–8: Намотка всередину
     - Фіксація кута повороту відповідно до вимог етикетувального автомата замовника.

4. **Інтерактивний полотняний візуалізатор (Canvas)**:
   - Масштабування (Zoom) та плавне панорамування (Pan).
   - Перемикання орієнтації перегляду: горизонтальне полотно (як у цеху) або вертикальне полотно.
   - Відображення міліметрових лінійок, контурів висічки, зони друку 305 мм, фотомiток (сенсорних міток для висічки).
   - Інтерактивний HUD-підказчик при наведенні курсору на будь-яку етикетку в струмку.

5. **Калькулятор тиражу та комерційний прорахунок**:
   - Розрахунок потрібної довжини рулону (нетто та брутто з урахуванням техвідходу та приладки).
   - Розрахунок площі матеріалу (м²).
   - Розрахунок повної вартості тиражу та собівартості 1 етикетки.
   - Калькулятор економії при виборі оптимальної орієнтації.

6. **Експорт у виробництво**:
   - **Print-Ready PDF**: генерація готового векторного PDF-файлу спуску на 330 мм рулон із мітками різу, оптичними фотометками та інфо-плашкою.
   - **Технічний паспорт замовлення**: бланк для погодження із замовником та для друкаря (зі схемою намотки, розмірами, кількістю струмків).

## Запуск додатку

### Варіант 1: Через файл запуску
Двічі клікніть по файлу:
```
start.bat
```

### Варіант 2: Через командний рядок
```bash
python app.py
```
Відкрийте у браузері: `http://localhost:8088`

---

## Структура проєкту

- `app.py` — бекенд веб-сервера на базі Tornado.
- `core/`
  - `pdf_inspector.py` — парсер PDF, виявлення контурів різу, витяг розмірів та генерація прев'ю.
  - `layout_engine.py` — алгоритми оптимізації розкладки, матриці координат, схеми FINAT 1–8.
  - `quote_calculator.py` — розрахунок тиражу, метрів, собівартості та економії.
  - `pdf_imposer.py` — генератор векторного спуску на 330 мм полотно (1000 мм) у форматі PDF.
- `static/`
  - `index.html` — інтерфейс користувача.
  - `css/custom.css` — стилі та правила друку.
  - `js/app.js` — логіка UI, стан, взаємодія з API.
  - `js/canvas.js` — інтерактивний візуалізатор полотна рулону з лінійками та мітками.
  - `js/schemes.js` — векторні діаграми напрямків намотки FINAT.
- `samples/` — тестові зразки етикеток.
- `uploads/` — тимчасові файли завантажень та згенеровані PDF.
